# הוראות התקנה והפעלה - מערכת FairPlay Chess Security

מסמך זה מפרט את הצעדים הנדרשים להרצת האפליקציה FairPlay במחשב המשתמש.

## 1. דרישות קדם (Prerequisites)
לפני תחילת ההפעלה, ודא שהרכיבים הבאים מותקנים במחשבך:
* תוכנת **Python 3.x:** מותקנת ומעודכנת.
* תוכנת **PostgreSQL:** מסד הנתונים שבו נמצאים הנתונים (מומלץ להריץ דרך Docker כפי שבוצע בפרויקט).
* **ספריות Python:** נדרשת הספרייה `psycopg2` לצורך התקשורת עם מסד הנתונים.

## 2. הגדרת סביבת עבודה
1. ודא ששרת ה-PostgreSQL שלך פעיל ומקשיב בפורט הסטנדרטי `5432` על `localhost`.
2. פתח טרמינל או CMD והנווט לתיקיית `phaseE` בפרויקט.
3. התקן את הספריות הנדרשות באמצעות הפקודה:
   ```bash
   pip install psycopg2

## 3. הפעלת המערכת
1. בתוך התיקייה phaseE, הרץ את הפקודה הבאה להפעלת מסך הכניסה:
python login_gui.py
2. מסך ההתחברות:
- הזן שם משתמש: admin
- הזן סיסמה: 1234
- לחץ על "הכנס למערכת".
3. לוח הבקרה (Dashboard):
- לאחר ההתחברות, ייפתח לוח הבקרה הראשי (main.py).
- מהלוח ניתן לגשת לכל 15 מסכי הניהול של הטבלאות ולמסך השאילתות המתקדם.
## 4. פתרון תקלות נפוצות
- שגיאת חיבור למסד נתונים: ודא ששרת ה-PostgreSQL פעיל ושהסיסמה המוגדרת בקוד (במשתנה db_config בכל קובץ GUI) תואמת לסיסמה שקבעת בהתקנת ה-Postgres שלך.
- שגיאה "ModuleNotFoundError": ודא שהתקנת את psycopg2 בסביבת ה-Python שבה אתה מריץ את הסקריפט.
- קבצים לא נמצאים: ודא שכל קבצי ה-GUI (כגון player_gui.py, main.py וכו') נמצאים באותה תיקייה (phaseE).
